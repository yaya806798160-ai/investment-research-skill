# Bayesian Valuation

## Objective
Convert uncertainty into explicit scenarios instead of pretending to know one precise fair value.

## Process
Create bear/base/bull cases.

For each:
- probability
- revenue growth
- margin
- earnings/FCF
- terminal assumptions
- valuation multiple
- implied value

Expected value = sum(probability × scenario value).

## Updating rule
Increase or decrease probabilities only when new evidence changes the likelihood of the underlying assumptions.

Do not update the thesis merely because the stock price moved.
