# Earnings Analysis Tool

## Objective
系统分析公司业绩：增长、质量、预期差与风险，支撑持有/买入/卖出决策。

## 分析步骤

### 1. 收入与利润
- 营收/净利润同比环比、增速趋势（多期）。
- 拆分：量 vs 价、分业务/分地区。
- 与业绩预告/快报/一致预期对比（预期差）。

### 2. 盈利能力
- 毛利率、营业利润率、净利率趋势。
- 费用率变化（S&M / R&D / G&A）。
- 经营杠杆是否兑现。

### 3. 现金流与质量
- 经营现金流 vs 净利润（含金量）。
- 自由现金流、资本开支强度。
- 应收账款/存货/合同负债变化。

### 4. 资产负债表
- 杠杆与偿债、商誉与减值风险。
- 股东回报：ROE/ROIC 及杜邦拆解。

### 5. 结论与信号
- 业绩好于/符合/低于预期。
- 关键问题与 red flags。
- 对估值与结论的更新。

## 输出
业绩分析报告：业绩摘要、趋势与预期差、质量评估、风险与结论更新。
