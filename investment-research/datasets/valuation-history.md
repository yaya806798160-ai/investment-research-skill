# Valuation History

## Objective
建立估值历史数据库规范，用于判断当前估值水平、历史位置与市场预期。

## 字段规范

| 字段 | 说明 |
|---|---|
| PE | 市盈率（TTM） |
| Forward PE | 预期市盈率 |
| PS | 市销率 |
| EV/Sales | 企业价值/销售收入 |
| EV/EBITDA | 企业价值/息税折旧摊销前利润 |
| FCF Yield | 自由现金流收益率 |
| PEG | 市盈率/盈利增速 |
| Historical Percentile | 当前值所处历史分位 |

## 用途
- 当前估值水平：与历史中枢、可比公司对比。
- 历史位置：分位判断贵/便宜。
- 市场预期：Forward PE 与隐含增长反映的预期。

## 维护规则
- 记录时间序列与窗口（如 5 年/10 年）。
- 标注口径（TTM/Forward、调整项）。
- 分位计算需注明样本区间。
