# Industry Map

## Objective
建立产业链地图数据库，重点覆盖 AI 产业链各环节的上中下游、核心公司与投资逻辑。

## 覆盖环节

- AI芯片
- GPU
- ASIC
- 半导体设备
- 光模块
- PCB
- 服务器
- 数据中心
- 电力基础设施
- 云计算

## 每个环节记录

| 维度 | 说明 |
|---|---|
| 上游 | 上游供应商/原材料/设备 |
| 中游 | 中游制造/集成环节 |
| 下游 | 下游客户/应用场景 |
| 核心公司 | 环节内的代表性公司 |
| 竞争格局 | 集中度、壁垒、份额 |
| 周期位置 | 扩张/放缓/收缩/复苏 |
| 投资逻辑 | 价值量与成长驱动 |
| 风险 | 技术、竞争、周期、地缘风险 |

## 使用规范
- 产业链定位决定估值与周期的分析起点。
- 环节间价值量与议价权差异大，需逐环节独立评估。
- 数据标注来源与更新日期。
