# Financial Data Layer

## Objective
定义财务数据资产：三张报表、估值、业绩与股本信息，支撑公司质量、成长性与估值分析。

## 数据范围

### 财务报表
- 利润表：营收、毛利、费用、营业利润、净利润、EPS。
- 资产负债表：资产/负债/权益、现金、商誉、借款。
- 现金流量表：经营/投资/筹资现金流、资本开支、自由现金流。
- 覆盖市场：A 股、港股、美股。

### 估值数据
- 个股估值：PE（TTM/LYR）、PB、PS、PCF、PEG、市值。
- 市场/指数估值：上证、沪深300、创业板指等的 PE 与市值。
- 港股/美股估值：PE/PB/PS、股息率、波动率。

### 业绩与预告
- 业绩预告、业绩快报、正式财报。
- 商誉与商誉减值、减值预期。

### 股本与股东
- 股本结构（总股本/流通/限售）、解禁批次与明细。
- 股东人数、十大股东/流通股东、增减持、管理层持股与薪酬。

### 其他
- IPO、重大合同、股权质押。
- 基金：净值、持仓、份额、费率、经理任职。

## 关键字段
- report_date / period
- revenue / gross_profit / net_income / ebitda
- total_assets / total_liabilities / equity
- ocf / icf / fcf / capex
- pe_ttm / pb / ps / peg / market_cap

## 使用规范
- 区分报告期与发布日期，避免用未来数据。
- 注意会计口径（合并/母公司、扣非）。
- 财务指标需与行业/周期结合解释，不孤立使用。
