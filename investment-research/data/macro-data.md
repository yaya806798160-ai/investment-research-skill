# Macro Data Layer

## Objective
定义宏观数据资产：增长、通胀、货币、信用、外贸与政策日历，为行业与资产配置提供宏观背景。

## 数据范围

### 增长
- GDP（季度，分产业）。
- 工业增加值、固定资产投资、社会消费品零售总额。

### 通胀
- CPI（全国/城市/农村）、PPI。

### 货币与信用
- M0/M1/M2、新增信贷、社会融资规模、LPR、存款准备金率。

### 财政与外贸
- 财政收入、税收收入、海关进出口。

### 储备与其他
- 外汇储备、黄金储备。
- 美国经济指标：ISM、非农、CPI/PPI、失业率、贸易帐、新屋开工、成屋销售、耐用品订单、消费者信心、GDP、联邦基金利率。

### 日历
- 交易日历（A 股/港股）、财经日历（宏观数据、IPO、财报、交易提醒）。

## 关键字段
- period（月度/季度/年度）
- value / yoy / mom / cum
- actual / forecast / previous

## 使用规范
- 宏观数据用于判断流动性与经济周期位置，不直接决定个股买卖。
- 对比预期（actual vs forecast）解读边际变化。
- 注意季节性与基期效应。
