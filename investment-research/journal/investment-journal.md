# Investment Journal

## Objective
记录每次投资决策与结果，积累可复盘的经验，减少重复错误。

## 字段

| 字段 | 说明 |
|---|---|
| Date | 决策日期 |
| Asset | 标的 |
| Action | 动作（买入/加仓/持有/减仓/卖出） |
| Reason | 决策理由 |
| Valuation | 决策时估值依据 |
| Expected outcome | 预期结果 |
| Actual outcome | 实际结果 |
| Lessons learned | 经验教训 |

## 用途
- 长期复盘投资错误与成功案例。
- 对比预期与实际，校准判断与流程。
- 沉淀规则：识别重复出现的错误模式。
