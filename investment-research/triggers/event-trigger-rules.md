# Event Trigger Rules

## Objective
定义事件触发条件：价格、基本面、新闻三类，命中后生成 Trigger Event Report 并派发任务。

## 价格触发
- Daily drop > X%：单日跌幅超过阈值。
- Breakout：突破关键位置（放量）。
- New high：创阶段新高。

## 基本面触发
- Earnings surprise：业绩大幅超预期/不及预期。
- Guidance change：指引上调/下调。
- Margin change：毛利率/利润率显著变化。

## 新闻触发
- Major policy：重大政策变化。
- Industry change：行业结构性变化。
- Company event：公司重大事件（并购、管理层、监管）。

## 输出
Trigger Event Report：事件描述、受影响标的、影响评估、建议动作。
