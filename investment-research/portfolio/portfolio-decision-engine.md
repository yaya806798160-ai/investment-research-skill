# Portfolio Decision Engine

## Objective
针对个人投资组合，基于持仓结构与风险状态输出组合层面决策。

## 输入
- Holdings：持仓清单
- Cost basis：成本
- Position size：仓位大小
- Asset category：资产类别

## 分析
- Concentration：集中度。
- Sector exposure：行业暴露。
- Correlation：相关性。
- Drawdown：回撤。
- Risk：风险。

## 仓位框架
- Core position：核心仓。
- Satellite position：卫星仓。
- Theme position：行业主题仓。
- Cash reserve：现金流仓/现金储备。

## 输出
Portfolio Decision：
- Keep：持有。
- Add：加仓。
- Reduce：减仓。
- Rebalance：再平衡。
