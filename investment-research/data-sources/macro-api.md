# Macro API Source

## 用途
宏观经济数据接口的接入与使用规范，为行业与资产配置提供宏观背景。

## 接口范围

### 国内
- GDP（季度）、CPI、PPI、PMI、LPR。
- M0/M1/M2、新增信贷、社会融资规模、存款准备金率。
- 工业增加值、固定资产投资、社零、财政收入、税收、海关进出口。
- 外汇与黄金储备。

### 海外
- 美国：ISM、非农、CPI/PPI、失业率、贸易帐、新屋开工、成屋销售、耐用品订单、消费者信心、GDP、联邦基金利率。

### 日历
- 交易日历（A 股/港股）、财经日历（宏观数据、IPO、财报、交易提醒）。

## 调用约定
- 周期参数：月度/季度/年度，返回 actual / forecast / previous 便于对比预期。

## 输出与规范
- 宏观用于判断流动性与经济周期，不直接决定个股买卖。
- 注意季节性与基期效应；解读边际变化而非绝对水平。
