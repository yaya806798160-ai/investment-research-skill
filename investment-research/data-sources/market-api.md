# Market API Source

## 用途
行情类数据接口的接入与使用规范，为研究流水线提供实时/历史行情输入。

## 接口范围

### 行情快照
- 个股/板块/指数最新行情：最新价、涨跌幅、成交量额、换手率。
- 支持按板块、交易所、上市日期过滤。

### 历史与分时
- K 线：分/日/周/月/年，前复权/后复权/不复权。
- 分时：1 分钟价格、均价、成交量。

### 资金与交易结构
- 个股/板块资金流向（主力、大单、中单、小单）。
- 北向/南向资金、涨停/跌停/炸板股池、大宗交易、融资融券。

### 跨市场
- 港股 K 线/指数、美股列表与历史日 K、期货日终与分钟 K 线。

## 调用约定
- 代码带市场后缀：600000.SH / 000001.SZ / 00700.HK / NVDA。
- 时间参数统一毫秒时间戳或 YYYYMMDD，注意时区（Asia/Shanghai）。
- 批量接口注意条数上限与分页。

## 输出与规范
- 输出字段：symbol、datetime、open/high/low/close、volume、amount、pct_chg。
- 标注数据截至时间；实时数据用于当刻决策，历史数据用于趋势与回测。
- 禁止编造行情；异常（停牌、无数据）需显式标记。
