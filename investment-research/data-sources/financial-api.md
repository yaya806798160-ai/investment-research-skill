# Financial API Source

## 用途
财务与公司数据接口的接入与使用规范，支撑质量、成长与估值分析。

## 接口范围

### 财务报表
- 利润表 / 资产负债表 / 现金流量表：A 股、港股、美股，按报告期或区间查询。
- 全市场同报告期批量报表。

### 估值
- 个股日估值：PE（TTM/LYR）、PB、PS、PCF、PEG、市值。
- 市场/指数日估值：上证、沪深300、创业板指等。

### 业绩与事件
- 业绩预告、业绩快报、正式财报。
- IPO、重大合同、解禁、股权质押、股东增减持、管理层信息。

### 基金
- 净值、持仓、份额、费率、经理任职、资产配置。

## 调用约定
- 用报告期（report_date / period）或日期区间过滤，二者互斥时注意校验。
- 区分 report_date（报告期）与 publish_date（发布日期）。

## 输出与规范
- 财务口径：合并/母公司、扣非、年化需显式标注。
- 禁止用未来数据回填；异常值需核对原始公告。
