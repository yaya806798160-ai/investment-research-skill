# User Command

## Objective
定义用户调用方式：自然语言命令映射到对应 Agent 与流程。

## 支持命令

### 1. "分析股票：NVDA"
调用：Industry Analyst → Company Analyst → Valuation Analyst → Risk Manager → 研究报告。

### 2. "检查我的组合"
调用：Portfolio Strategist / Risk Manager → 组合状态与风险报告。

### 3. "今天市场怎么样"
调用：Market Review / Macro Analyst → 市场与宏观简报。

### 4. "有没有值得关注机会"
调用：Opportunity Analyst / Opportunity Ranking → 机会清单。

### 5. "我要买入，帮我检查"
调用：Action Recommendation Engine / Risk Manager / Execution Discipline → 买入前检查与行动建议。
