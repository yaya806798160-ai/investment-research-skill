# Investment History

## Objective
定义投资历史数据库，用于分析长期投资表现。

## 记录字段

| 字段 | 说明 |
|---|---|
| Asset | 标的 |
| Entry Date | 建仓日期 |
| Entry Price | 建仓价格 |
| Position Size | 仓位大小 |
| Exit Date | 退出日期 |
| Exit Price | 退出价格 |
| Return | 收益率 |
| Holding Period | 持有期 |
| Decision Quality | 决策质量评价 |

## 用途
- 分析长期投资表现与决策质量。
- 结合 decision-memory 与 decision-review，定位收益/损失来源。
